# college-navigator
---
## Основний функціонал
- **Побудова маршрутів:** Пошук найкоротшого та альтернативних шляхів між обраними точками на 3 поверхах.
- **Інтерактивна карта:** Вибір початкової та кінцевої точки одним кліком прямо на SVG-схемі.
- **Зручне керування:** Перемикання між поверхами за допомогою стрілок на клавіатурі (`ArrowUp` / `ArrowDown`).

## Використані технології
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Node.js, Express
- **Database:** SQLite
